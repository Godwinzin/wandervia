# Wandervia

**Wandervia** is a modern, responsive single-page travel exploration and booking web application built with React and Vite. Designed to provide a seamless user experience, Wandervia enables travelers to discover curated destinations, filter listings by price range and categories, view real-time weather conditions and interactive maps via Leaflet, and manage their saved wishlist and active bookings.

---

## Key Features

* **Dynamic Destination Discovery:** Browse through gorgeous destination cards complete with pricing, status badges, and quick-save wishlist heart toggles.
* **Interactive Search & Filtering:** Filter destinations instantly using custom criteria and price sliders.
* **Detailed Destination Views:** Access multi-photo galleries, integrated Leaflet map locations, live weather cards, and interactive booking widgets.
* **Wishlist Management:** Save and manage favorite destinations locally with instant state updates.
* **Booking System:** Review, submit, and track reservations with instant toast notifications.
* **Fully Responsive Design:** Features a sticky navigation bar with a smooth, compact mobile hamburger menu and a multi-column polished footer.

---

## Tech Stack

* **React (v19)** – Component-based UI architecture
* **React Router (v7)** – Client-side multi-page routing and `NavLink` active states
* **Vite** – Lightning-fast build tool and development server
* **Leaflet & React-Leaflet** – Interactive location mapping
* **Lucide React & Custom SVGs** – Modern iconography
* **CSS3** – Custom responsive styling utilizing CSS variables, Flexbox, and CSS Grid
